1-2 · 개념

데이터베이스 = 규칙이 있는 표

관점엑셀 · 메모장데이터베이스
구조칸마다 자유 입력열마다 종류 고정 (날짜 · 숫자 · 글)
중복같은 와인 세 번 입력 가능규칙으로 차단
질문눈으로 찾기 · 필터"90점 이상 프랑스 와인" → 즉시 목록

용어표 = 테이블 · 가로줄 = 행(1건) · 세로줄 = 열(항목)

1-3 · 개념

Supabase = 주소가 있는 표 보관소

로컬 파일우리 집 냉장고 · 내 컴퓨터에서만 접근
Supabase주소(URL)가 있는 보관소 · 어느 기기에서나 접근
무료 범위개인 노트 수준 충분 · 프로젝트 2개
안의 것PostgreSQL 표 · 대시보드에서 눈으로 확인 가능

비유로컬 = 우리 집 냉장고 · URL = 배민에 등록된 가게 주소
